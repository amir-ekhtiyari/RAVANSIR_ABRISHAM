# وب‌سایت شرکت حمل‌ونقل بین‌المللی روان سیر ابریشم

وب‌سایت سه‌زبانه (فارسی راست‌به‌چپ، انگلیسی و ترکی استانبولی) با Django و قالب‌های Django (بدون React یا SPA). حالت روشن و تیره دارد و محتوای آن از پنل مدیریت قابل ویرایش است.

## اجرا روی سیستم خودتان (ویندوز)

```bat
cd "F:\MY PROJECTS\RavanSir_Abrisham"
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

- سایت فارسی: http://127.0.0.1:8000/
- سایت انگلیسی: http://127.0.0.1:8000/en/
- سایت ترکی استانبولی: http://127.0.0.1:8000/tr/
- پنل مدیریت: http://127.0.0.1:8000/admin/

دستور `migrate` اطلاعات رسمی شرکت را هم وارد می‌کند: پنج خدمت، پنج مسیر فعال، چهار نوع ناوگان، و ایمیل و تلفن‌ها.

## صفحات

| صفحه | فارسی | انگلیسی (ترکی: `/tr/...`) |
|---|---|---|
| خانه (همه بخش‌ها) | `/` | `/en/` |
| خدمات + صفحه هر خدمت | `/services/` ، `/services/<slug>/` | `/en/services/` |
| مسیرهای فعال | `/routes/` | `/en/routes/` |
| درباره ما | `/about/` | `/en/about/` |
| تماس و فرم مشاوره | `/contact/` | `/en/contact/` |
| سئو | `/robots.txt` ، `/sitemap.xml` | |

## مدیریت محتوا (پنل مدیریت)

- **اطلاعات شرکت:** نام، معرفی، ایمیل، تلفن‌ها، نشانی (تا وقتی خالی است، نمایش داده نمی‌شود)، لوگو، **عکس اصلی بالای صفحه** و **عکس بخش معرفی**.
- **خدمات، مسیرها و ناوگان:** متن فارسی و انگلیسی، ترتیب، فعال یا غیرفعال، و **عکس واقعی برای هر نوع ناوگان**.
- **درخواست‌های مشاوره:** همه فرم‌های ارسالی با وضعیت پیگیری و یادداشت داخلی.

> **تصاویر:** تا وقتی عکسی در پنل بارگذاری نشده باشد، بخش بالای صفحه یک صحنه شبانه جاده با کامیون (طرح خطی فنی) نشان می‌دهد و کارت‌های ناوگان نقشه فنی هر کامیون را. با بارگذاری عکس واقعی در «اطلاعات شرکت ← تصویر اصلی صفحه» (عکس افقی از کامیون در جاده، حداقل ۲۰۰۰ پیکسل عرض، WebP یا JPEG) و در «ناوگان ← عکس»، عکس‌ها به‌طور خودکار جایگزین می‌شوند.

## ترجمه‌ها

متن‌های ثابت در `locale/fa/LC_MESSAGES/django.po` و `locale/tr/LC_MESSAGES/django.po` هستند. اگر ابزار gettext نصب باشد، بعد از هر تغییر این دستورها را اجرا کنید:

```bash
python manage.py makemessages -l fa -l tr
python manage.py compilemessages
```

متن خدمات، مسیرها و اطلاعات شرکت به سه زبان در پنل مدیریت ویرایش می‌شود. اگر متن ترکی یک مورد خالی بماند، نسخه انگلیسی آن نمایش داده می‌شود.

## انتشار روی سرور

1. فایل `.env.example` را با نام `.env` کپی و مقادیرش را پر کنید: `DJANGO_DEBUG=0`، کلید مخفی، دامنه، `SITE_URL` و در صورت نیاز PostgreSQL و SMTP.
2. اجرا کنید:
   ```bash
   pip install -r requirements.txt "psycopg[binary]" gunicorn
   python manage.py migrate
   python manage.py collectstatic --noinput
   python manage.py check --deploy
   gunicorn ravansir_abrisham.wsgi:application --bind 127.0.0.1:8000 --workers 3
   ```
3. در nginx مسیرهای `/static/` و `/media/` را مستقیم از پوشه‌های `staticfiles/` و `media/` سرو کنید و بقیه درخواست‌ها را به gunicorn بدهید. هدر `X-Forwarded-Proto` را هم بفرستید.

برای دریافت ایمیل هر درخواست مشاوره، `CONTACT_NOTIFY_EMAILS` و تنظیمات SMTP را در `.env` پر کنید. بدون این تنظیمات، درخواست‌ها فقط در پنل مدیریت ذخیره می‌شوند.

## ساختار پروژه

```
ravansir_abrisham/   تنظیمات و آدرس‌ها (i18n: فارسی بدون پیشوند، انگلیسی با /en/)
core/                اطلاعات شرکت، سئو، sitemap و robots، context processor، تگ‌های قالب
pages/               خانه، مسیرها، درباره ما
services/            مدل‌های خدمت، مسیر و ناوگان (+ داده اولیه)
contact/             فرم مشاوره (اعتبارسنجی سمت سرور، CSRF، honeypot، محدودیت تعداد درخواست)
templates/           base.html، partials/ (navbar، footer، hero، کارت‌ها، فرم)، pages/
static/              css/site.css (توکن‌های رنگ برای حالت روشن و تیره)، js/site.js، فونت‌ها (Vazirmatn و Space Grotesk)
tools/               ساخت طرح‌های خطی کامیون
```

## تست

```bash
python manage.py test
```

۱۵ تست صفحات فارسی و انگلیسی، سئو، sitemap و فرم تماس را پوشش می‌دهند: اعتبارسنجی، CSRF، honeypot، محدودیت تعداد درخواست و ارسال ایمیل.

## عکس‌ها، نقشه و پرچم‌ها

- **عکس‌های واقعی** در پوشه‌ی `static/images/photos/` هستند و با نامشان به هر بخش وصل می‌شوند. فهرست نام‌ها در `README.txt` همان پوشه است. برای عوض کردن یک عکس کافی است فایلی با همان نام جایگزینش کنید. عکس‌هایی که در پنل مدیریت بارگذاری شوند (هیرو، معرفی و ناوگان) اولویت دارند.
- **نقشه‌ی مسیرها** نقشه‌ی جغرافیایی واقعی است و از `tools/build_route_map.py` ساخته می‌شود. داده‌ی مرز کشورها از github.com/johan/world.geo.json (مالکیت عمومی) است.
- **پرچم‌ها** در `static/images/flags/` هستند و از پروژه‌ی flag-icons با مجوز MIT آمده‌اند.
